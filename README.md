\# InternTrack



\## Internship \& Job Application Tracker



InternTrack is a Java Swing desktop application designed to help students discover internship and job opportunities, check eligibility, apply for suitable roles, track applications, manage interviews, and receive application updates.



\## Features



\- Student profile management

\- Internship and job opportunity browsing

\- Eligibility checking

\- Application submission and tracking

\- Application status updates

\- Recommended roles based on student skills

\- Interview management

\- Application notifications

\- Search functionality

\- Application reports and statistics

\- File-based data persistence

\- Background interview reminders
